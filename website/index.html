v0.1.0 · C23 · no GC · one binary

Web apps in C,
end to end.

Routes, models, forms and the DOM are C you compile — once for the server, once for the browser. Arenas instead of a collector, green threads instead of callbacks, and a gate on every surface instead of a promise.

Quickstart Read the reference

webc new myapp --template=fullstack 21 opt-in modules 58 headers

src/view.c 
// src/view.c — one page, rendered on the server
// and again in the browser
#include <webc/shared.h>

WEBC_MODEL(Todo, (id, i64, .pk = true), (title, Text), (done, bool))
Vec(Todo)

view(Todos, VecTodo *todos) {
  el("main") {
    el("h1") { text("Todos"); }

    el("form") { post_to("/api/todos");
      el("input") { name("title"); required(); }
    }

    el("ul") {
      for_each(t, (*todos)) {      // keyed: a row keeps its node
        el("li") { class_(t->done ? "done" : "");
          el("span") { text(t->title); }
        }
      }
    }
  }
}

the shape of it

One language. Two halves. No bridge to write.

The server renders the page; the same views compile to wasm and hydrate the markup the server already sent. An action is a function, a render follows it, and the boundary between the halves is a file listing — not an API.

Routes are declarations

src/server.c
// src/server.c — routes are declarations
#include <webc/server.h>

WEBC_MODEL(Todo, (id, i64, .pk = true), (title, Text), (done, bool))
Vec(Todo)
declare_view(Todos, VecTodo);

GET("/")          { return page(Todos, db_all(Todo)); }
GET("/api/todos") { return json(200, db_all(Todo)); }

POST("/api/todos") {
  Todo t = body(Todo);      // form or JSON, validated
  db_save(Todo, &t);
  return json(201, Todo, &t);
}

Handlers are typed, the router is a table the compiler checks, and a bad request is a response — not an exception somewhere else.

The browser half is a file

src/client.c
// src/client.c — the browser half is a file
#include <webc/web.h>
#include <webc/shared.h>

WEBC_MODEL(Todo, (id, i64, .pk = true), (title, Text), (done, bool))
Vec(Todo)
declare_view(Todos, VecTodo);

static VecTodo g_todos = {.desc = &WC_VECDESC_VecTodo};

// a render follows every action
action(toggle, Todo *t) { t->done = !t->done; }

client_main {
  mount(Todos, &g_todos, "#root");   // adopt the markup
  bind("toggle", "click", toggle);
  return 0;
}

Same view, same types. action_live is the escape hatch for a pointer move: it writes one node and skips the render.

the floor

What the framework decided, so you do not have to

Six rules that shape every API in the box. They are why an app has no malloc, no error-string plumbing, and no second way to do the same thing.

C23, and only C23

No preprocessor tricks beyond macros, no GC, no hidden allocation. Every allocation goes through wm_alloc or an arena you can see.

Arenas, not a collector

The framework installs one arena per scope — process, request, render — and resets it in O(1). An app says fmt() or persist(), never “arena”.

Green threads

M:N on kqueue: channels, select, timers, mutexes, wait groups. A handler that awaits is a handler that costs a few kilobytes.

One language, two halves

The same view compiles to the server binary and to wasm32-wasip1. The browser half hydrates the markup the server already sent.

Typed all the way down

Routes, models, forms, JSON and migrations are macros the compiler checks. A typo is a compile error, not a 500 at 3 a.m.

The boundary, generated

The API leaves the app as it was declared: webc openapi writes OpenAPI 3.1 and webc client --ts a typed fetch client, from the routes and models themselves — and webc deploy --pack writes the ops files that run the binary. Generated once, owned from then on, ratcheted in CI.

A gate for every surface

webc api, webc lint, make budget: the public names, the leaks and the bytes are all counted on every build.

One page for every module

When something in WebC looks surprising, the reason is written down — and so is what it costs. “C23, not C11. Cost: no MSVC path yet.” That is the pattern behind every non-obvious choice in the framework, and the reference spells out both halves: the language, the modules, and the price of each.

the gate

Every surface is counted

webc api counts the public names and fails when the list grows without saying so. webc lint fails when a name from the developer surface leaks into an app, an example, a scaffold or the docs. make budget fails when the wasm or the binary grows past its number. The framework's own repository is the first thing they run against.

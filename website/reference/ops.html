Docs/Reference/15. Ops

15. Ops

Reference · docs/reference.md

  • Logs: log_info("request", { "path", req->path }, { "status", ... }). Text by

    default, JSON with WEBC_LOG=json; level from WEBC_LOG_LEVEL.

  • Metrics: metrics_counter_inc, metrics_observe; /metrics in Prometheus format

    when WebcOptions.metrics is set. The server exports webc_conns, webc_tasks, webc_requests_total and the connection-close counters webc_conn_closed_eof_total (the client closed: normal keep-alive end), webc_conn_close_idle_total, webc_conn_close_partial_total (a request was cut short) and webc_conn_read_error_total (a read failed on our side — the one counter that should stay at zero).

  • /debug reports heap, arenas, tasks and route count; /debug/cpu?ms=2000 runs the

    sampling profiler for one window and prints a flat profile, and webc_profile_start() / webc_profile_stop() / webc_profile_report() do it from code. The sampler signals every process thread — including threads the runtime does not own — from a dedicated thread, and never itself.

  • Limits, all answerable: `WebcOptions{ .max_body, .max_header_bytes, .header_timeout_ms,

    .max_conns, .max_multipart_parts, .max_multipart_bytes, .max_json_depth }`. A body over the limit is a 413, headers over the limit a 431, JSON nested deeper than 256 a 400 that says so.

  • Multipart (<webc/multipart.h>): multipart_parse() plus

    model_from_multipart(), so a form with a file lands in the same model as one without. Part and byte limits are arguments.

  • Redis and the query cache add their counters to the same list (§9d): webc_cache_* for what

    the cache did and webc_redis_* for what the wire did. WEBC_TRACE_CACHE=1 prints one line per statement ([cache] select … -> hit), WEBC_TRACE_DB=1 prints the statements themselves.

  • Budgets are a gate: make budget measures SPEC §10 and exits non-zero on a miss (SSR ≥ 100k

    req/s, 1 KB JSON ≤ 1 µs, patch ≤ 0.2 ms, wasm hello ≤ 24 KiB gzip, serve binary ≤ 460 KiB, cold build ≤ 1500 ms). The serve binary's line moved from 400 KiB to 460 KiB when Redis and the cache became part of it — hello measured 456 544 B on the machine this was written on; make redis-test runs the client and the cache against a real redis-server.

  • Shutdown: SIGINT/SIGTERM stop accepting, drain for drain_ms, then exit.

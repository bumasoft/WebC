5. JSON and forms

Reference · docs/reference.md

JsonWriter (streaming, depth-bounded) for output, JVal (tree, depth-bounded) for input. The parser refuses input deeper than WC_JSON_MAX_DEPTH (256) instead of growing the stack. Unknown keys on input are ignored; a field that fails validation comes back as a WErrs list of {field, message}.

Writing a response:

you havewritewhy
one rowjson(200, Todo, &t)a Todo * carries nothing to recover the model from, so name it
a collectionjson_list(200, rows)the descriptor is in the struct, and ->desc is checked by the compiler
bytes that are already JSONjson(200, some_str)a tree rendered elsewhere, or another service's payload
an errorres_error(422, "bad_email", "…")a flat {error, message} an app can act on

json(200, rows) also works for a collection — it is the same bytes — but the argument goes through void *, so a slip is a runtime answer (500 json_not_a_vector, one log line) where json_list makes it a compile error.

Writing a document by hand — a payload in a shape no model has, or a fragment for someone else's API — is the writer, and its two costs are brackets and empty strings:

c
// src/api/ingest.c — a payload in a shape no model has, built by hand
#include <webc/server.h>

WEBC_MODEL(Todo, (id, i64, .pk = true), (title, Text, .required = true),
                    (author_name, Text))
Vec(Todo)

static str hand_built(Todo *post, const char *const *KEYWORDS) {
  JsonWriter w = jw_doc();                          // the document lives in the scope arena
  jw_obj_begin(&w);
  jw_kv_cstr(&w, "headline", post->title);         // key + value, or neither when it is empty
  jw_obj_in(&w, "author") {                        // { "author": { … } }, closed for you
    jw_kv_cstr(&w, "name", post->author_name);
    jw_arr_in(&w, "roles") { jw_str(&w, str_lit("writer")); }
  }
  jw_kv_str_list(&w, "keywords", KEYWORDS);        // a null-terminated list; no list, no key
  jw_obj_end(&w);
  return jw_finish(&w);
}

jw_obj_in / jw_arr_in are the el(...) pattern applied to the writer: the block closes itself, break and return included. jw_kv_* skips the key and the value when the value is absent, because "datePublished":"" is not a date — it is a claim a reader has to guess about. jw_str escapes JSON; it does not escape HTML, and the next section is why that distinction has a name.

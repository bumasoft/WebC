Minimal

The bundle floor: what a page costs when it asks for nothing.

webc devrun it from examples/minimalopen on GitHub

main.c

examples/minimal/main.c
// examples/minimal — the hello-world the wasm bundle budget is measured on
// (SPEC §10: ≤ 24 KB gzip, bridge included). One signal, one component, one action:
// whatever this weighs is the floor a WebC frontend app costs.
//
// It is also the smallest honest client app: a view that reads a state slot, an action
// that changes it, and a button that names the action where the button is written. The
// markup is a designed page rather than three bare tags — that costs bytes in `main.c`,
// not in the bundle — and the stylesheet is a plain file beside it (`public/style.css`),
// because a page that looks like nobody meant it teaches the wrong thing about the floor.
#include <webc/web.h>

state(i64, clicks, 0);

ACTION(inc)   // the action below, declared for the view that wires it

view(Counter) {
  el("main") {
    class_("card");
    el("header") {
      class_("head");
      el("span") { class_("mark"); attr("aria-hidden", "true"); text("W"); }
      el("h1") { text("Hello, WebC"); }
    }
    // The number is the page. `aria-live` is on the pair, not on the figure: a screen
    // reader should hear "3 clicks", and a bare "3" is a number with no unit in it.
    el("p") {
      class_("readout");
      attr("aria-live", "polite");
      el("span") { class_("count"); text("%lld", (long long)get(clicks)); }
      el("span") { class_("unit"); text(get(clicks) == 1 ? "click" : "clicks"); }
    }
    el("button") { on_click(inc); text("+1"); }
    el("p") { class_("foot"); text("one signal · one view · one action"); }
  }
}

action(inc) { set(clicks, get(clicks) + 1); }

client_main {
  mount(Counter, "#root");
  return 0;
}

public/index.html

The whole document: a viewport, a stylesheet, a mount point and WebC.start(). Nothing here is app logic — the page is wasm, and this is the page it lands in.

public/style.css

The look, in one file and one class per element. Shown here up to the card, the brand mark and the heading; the rest is the big number, the button, the dark half and the phone case.

examples/minimal/public/style.css
/* The minimal app's whole look, in one file. The example is about how little code a page
   needs, and a page still has to look like somebody meant it: two colours, one accent, a
   card in the middle, and the count as the one big thing on the screen.

   Every colour is a token and the dark half is the reader's OS, not a second stylesheet. */

:root {
  color-scheme: light dark;
  --bg: #f3f4f9;
  --card: #ffffff;
  --fg: #14161c;
  --muted: #545b6b;
  --faint: #6f7787;
  --line: #e4e7f0;
  --line-strong: #d3d8e6;
  --accent: #4b56e8;
  --accent-hover: #3b46d6;
  --on-accent: #ffffff;
  --glow: rgba(75, 86, 232, 0.16);
  --shadow: 0 1px 2px rgba(16, 20, 32, 0.06), 0 22px 48px -28px rgba(16, 20, 32, 0.45);
  --font: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", sans-serif;
  --radius: 20px;
  --gutter: 24px;
}

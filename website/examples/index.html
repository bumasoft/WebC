All examples

Eight apps live in the repository. Each builds, each passes its own tests, and each one is small enough to read in a sitting. They are not toys: the board is the reference for live rooms and drag-and-drop, the accounts app is the reference for sessions.

examples/hello

Hello

A finished first page: a greeting form, a JSON endpoint, and one shared model.

Run them

Every example is a project of its own. From the repository root:

bash
cd examples/board
webc dev            # build, serve, reload on save
webc test           # its own suites

# `webc size --modules` builds. Checked by `make budget`; a module over its line fails the
# build the way the wasm budget does.
#
# The number is a *ceiling with room*, not the measurement of the day: a module that grows a
# little should not break the build (that is `webc api`'s job, and it is exact), but a module
# that doubles should. `webc size --modules --check tools/module-budgets.txt` prints every
# line, measured against this file.
